# features.md — SWEnder (short list)

## MVP Core
- Verified Student — .edu email gate before matching/chat.
- Office Hours — publish free blocks; only show people with overlap.
- Max 3 Open Chats — hard cap; archive one to start another.
- One Intro a Week — single curated intro, no infinite swipe stack.
- Double-Opt-In Date Card — both accept place/time before chat unlocks.
- Busy Mode — pause intros during midterms/hackathons/interviews.
- First Meet Ideas — study hall, coffee, campus walk templates.
- Safety Share Plan — share who/where/when + check-in ping.
- Privacy Defaults — no mutuals, no who-viewed-you, no public scores.

## Matching
- SWEnder Matching — match on agents/models/token-usage fingerprint.
- Merge Conflict — opt-in worst-stack / rival-tech pairing.
- Dependency Hell — match chronically overcommitted people.
- Semantic Versioning — intent as major/minor/patch compatibility.
- Hot Reload — one bump to revive a dead chat with a fresh icebreaker.

## Enemies → Lovers
- Enemies-to-Lovers Randomizer — pair statistical worst matches as a dare.
- Super Left — hard reject; mutual Super Left unlocks rivals queue.
- Merge After Conflict — badge/lore after rival pair survives N messages.
- Rubber Duck Duel — argue each other's hated tech for 3 minutes.
- Soft Fork — shift from roast mode to genuine curiosity.

## CS Identity Labels
- Infinite Loop — keeps dating the same type.
- Verified Commit — wants something serious.
- Force Push — moves fast / chaotic style.
- Open Source — open/non-monogamy, labeled.
- Localhost Only — campus / in-person first.
- Works On My Machine — overconfident energy.
- 404 Emotional Availability — self-aware avoidant.
- Premature Optimization — too serious too fast.
- Tech Debt — unfinished situationships disclosed.
- Agile — short dating sprints.
- Big O Energy — ambitious / scales fast.
- Garbage Collected — recently single, cooling down.

## Game Layer
- Dating XP & Season Pass — XP for dates/replies/hack collabs.
- Level Unlocks — icebreakers, almost-matched, rivals queue, legend frame.
- Power-Ups — Stack Overflow, Undo Commit, Priority Queue, Rubber Duck.
- Prank Items — timed sudo bio edit, SIGSTOP swipe freeze, meme fork-bomb, read-receipt rollback (opt-in).
- Leaderboards — silly campus boards; hideable; no swipe-count creep.

## Hackathon Track
- Hackathon Partner Tag — reclassify a match as teammate, not romantic.
- Partner Request (PR) — structured “hack this weekend?” card.
- Team Compatibility — skills + schedule + conflict-style score.
- Ship Happens — verify a submitted hackathon project together.
- Shared Victory Loot — badges/power-ups for wins with app-met partner.
- Post-Hack Retro — what worked / broke / ship again.
- Spectate Mode — friends emoji-cheer a hack weekend.

## Campus Extras
- Code Review Flirting — kind snippet review as icebreaker.
- Pairing Session — timed 45-min pair challenge.
- Blame Game — cute git-blame story stickers.
- Nightly Build — late-lab pool, expires 2am.
- Rollback Plan — graceful non-ghost end templates.

## Safety
- Consent Flags — opt-in required for chaos/pranks.
- Rate Limits — scarce Super Lefts/pranks/rival matches.
- Block / Report Wins — real block always overrides game mechanics.
